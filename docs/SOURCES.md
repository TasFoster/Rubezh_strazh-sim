## Как использовать сведения

В модель включаются только подтверждённые свойства либо явно названные учебные
допущения. Выводы из рисунков отмечаются отдельно. Полнота схемы Zod и успешный
тест не подтверждают соответствие аппаратуре.

Для каждой реальной модели перед выпуском нужны: документ и редакция, номера
страниц, схема клемм, электрические параметры, настройки и проверка поведения.
До сверки интерфейс контроллера обозначается как учебная панель, а не точная
копия конкретной версии прошивки.

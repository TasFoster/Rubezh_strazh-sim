# Улучшения после обзора проекта — 21.10.2026

Проверены редактор, геометрия, хранение проектов, схемы данных, расчёт цепей,
настройки контроллеров, учебные примеры и проверки сборки.

## Интерфейс

В шапке и основной панели осталось семь кнопок. Частые действия — отмена,
повтор и запуск/пауза — доступны сразу. Режим, инструмент рисования и этаж
выбираются списками. Остальные команды собраны в меню:

| Меню | Команды |
|---|---|
| Проект | Новый объект, открытие, экспорт, примеры |
| Вид | Сетка, свойства плана, этажи, раздвигание и компоновка |
| Симуляция | Приборы, сброс, отдельное окно каждого контроллера |
| Помощь | Справка и задания |

Меню поддерживают стрелки, Home/End, Escape, Tab и закрытие щелчком снаружи.
Названия новых одинаковых компонентов получают номера. Идентичные названия
контроллеров после ручного переименования не создают конфликт ключей интерфейса.
Камера учитывает текущий этаж, повёрнутые карточки и геометрию плана.

## Коллизии

- При добавлении, копировании, повороте и перетаскивании карточка получает
  ближайшее свободное место среди проверяемых кандидатов. Учитываются размер,
  поворот и зазор. Разные этажи не мешают друг другу.
- При переходе к клеммам карточки раздвигаются с учётом увеличившегося размера.
  Команда «Развести компоненты» исправляет существующие наложения одним
  действием с отменой. Автоматическое раздвигание можно отключить.
- Для автоматических кабелей используется ограниченный поиск A* по
  ортогональной сетке координат препятствий. Учитываются вывод от клеммы,
  зазор до корпуса, повороты, занятые трассы и цена пересечений. Стоимость
  рёбер кешируется в пределах поиска. Результат мемоизируется в интерфейсе:
  тики симуляции сами по себе не запускают трассировку.
- Пересечения, которые остались после разведения, обозначаются дугами без
  электрического соединения. У произвольного графа соединений может не быть
  плоской разводки без пересечений; полное устранение пересечений не обещается.
- Ручные маршруты старых проектов сохраняются. Двойной щелчок по автомаршруту
  переносит его форму в ручные узлы и вставляет новый узел в выбранный сегмент.
  Автоматический режим возвращается через свойства кабеля.
- Перекрытый выход от клеммы и пересечение корпуса ручной трассой показываются
  как конфликты. Поиск имеет ограничение объёма; при неудаче путь через корпус
  не подставляется. Для произвольного поворота используется консервативная
  прямоугольная граница карточки.

Геометрия не меняет клеммные соединения, длину, сечение, обрывы или параметры
устройств. Перемещение карточек сохраняется в проекте и отменяется историей;
автоматические трассы вычисляются заново при отображении.

## Исправления надёжности

| Проблема | Исправление |
|---|---|
| Незавершённый провод или калибровка переносились в другой контекст | Единый сброс при смене этажа, режима и проекта |
| Delete в окне контроллера мог удалить выбранный компонент | Горячие клавиши редактора отделены от диалогов и меню |
| Последняя правка могла потеряться до таймера автосохранения | Проверяемое сохранение при скрытии/закрытии страницы |
| Вкладка могла затереть сохранение, изменённое извне | Сравнение с последней известной записью перед записью; конфликт сохраняет чужие данные |
| Некорректная карта могла сделать проект несохраняемым | Проверка конфигурации до добавления карты, проверка существующих прав |
| Импорт позволял назначить одно реле нескольким точкам | Проверка занятости и существования реле в ядре |
| Маска принимала непоследовательные единичные биты | Проверка маски подсети |
| Старый формат фона мог ссылаться на неизвестный этаж | Проверка ссылки при импорте |
| Штатное снятие питания с замка считалось ошибкой | Диагностика учитывает режим замка и команду открытия; обрыв в покое по-прежнему определяется |
| Окно контроллера можно было увести за экран | Ограничение положения при перетаскивании и изменении окна браузера |

Проверка изменения сохранения между вкладками является оптимистической защитой,
не системой совместного редактирования.

## Проверки

- `npm run check`: Biome, TypeScript, 61 модульный тест, production-сборка.
- `npm run test:e2e`: 15 сценариев Chromium, включая монтаж, проход, планы,
  задания, клавиатуру меню, коллизии, перестроение и отмену проводов, ручной
  маршрут, немедленную перезагрузку, конфликт сохранения и два окна контроллеров.
- `npm run test:e2e:production`: повторный запуск и проход без сети.
- Визуальная проверка плана и монтажа на 1366×768; проверка границ окна
  контроллера после уменьшения до 1024×700. Firefox/Safari отдельно не запускались.
